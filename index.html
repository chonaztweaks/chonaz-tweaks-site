FAQ

GOOD TO KNOW.

Will these tweaks guarantee more FPS?

No. Results depend on your hardware, game mode, settings and current bottleneck. The goal is to measure performance and avoid tweaks that make things worse.

Is the panel safe?

Review every script before running it, create a backup, and avoid tools that disable Windows Security, anti-cheat, driver-signature enforcement or core services.

Which PCs will it support?

The initial project is being designed around Windows 11 gaming PCs. Specific compatibility details should be published alongside each release.
